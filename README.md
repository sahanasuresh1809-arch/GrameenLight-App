GrameenLight

GrameenLight is an Android application developed to help villagers report faulty streetlights and enable Panchayat authorities to manage and track complaints efficiently.

The application focuses on improving public safety, reducing electricity wastage, and supporting smart village initiatives through community participation.

---
 Features

* Streetlight complaint reporting
* Complaint ID generation
* Complaint status tracking
* Authority dashboard for status updates
* Local data storage using Room Database
* Realtime cloud sync using Firebase Firestore
* Simple and user-friendly UI

---

Technologies Used

* Kotlin
* Jetpack Compose
* Material 3
* Room Database
* Firebase Firestore
* MVVM Architecture
* Navigation Compose

---
 Complaint Workflow

1. Resident reports a faulty streetlight
2. Complaint is stored locally using Room DB
3. Data is synced to Firebase Firestore
4. Authority updates complaint status
5. Resident can track complaint progress

---

Complaint Status

* Reported
* Assigned
* Fixed

---

## Project Goal

The main goal of GrameenLight is to provide a simple digital platform for village streetlight monitoring and complaint management.
